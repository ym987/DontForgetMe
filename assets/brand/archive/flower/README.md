# Archived: forget-me-not flower mark

The app's first logo (October 2026): a forget-me-not flower whose five petals are
hearts, around a golden center. It was replaced by the car mark because the
flower's meaning is less familiar to Hebrew speakers.

- `logo.svg`, `icon.svg`, `icon-512.png`: the vector logo, square icon and Play Store icon
- `geometry.mjs`, `generate.mjs`: the generator as it was. To regenerate every asset
  with the flower, check out the git tag `brand-flower-v1` and run
  `node scripts/brand/generate.mjs`.
